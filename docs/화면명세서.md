# KOWEPO Anomaly Dashboard 화면 명세서

## 1. 문서 개요
- 프로젝트명: `kowepo-anomaly-dashboard`
- 작성일: 2026-05-08
- 기준 소스: `src/App.tsx`, `src/components/*.tsx`
- 비고: 현재는 API 연동 전 단계의 프론트엔드 시뮬레이션 화면

## 2. 공통 레이아웃
- 좌측 사이드바
  - 메뉴: 관제 지도, 설비 모니터링, 이상 징후 이력, AI 분석, 유저 관리
  - 축소/확장 토글 지원
- 상단 헤더
  - 화면 제목/부제
  - 검색 입력(시각 요소)
  - 다크/라이트 테마 토글
  - 현재 시각 표시
  - 알림/사용자 버튼(시각 요소)
- 메인 컨텐츠
  - 탭 전환 시 페이드/슬라이드 애니메이션

## 3. 화면 목록

### 3.1 관제 지도 (`map`)
- 컴포넌트: `MapView`
- 목적: 발전소 위치 기반 통합 상태 확인
- 주요 UI
  - 대한민국 SVG 지도
  - 발전소 마커 5개(김포, 서인천, 태안, 평택, 군산)
  - 좌/우 발전소 정보 카드(주소, 설비용량, 발전대수, 상태)
  - 상태 범례(Normal/Caution)
- 사용자 동작
  - 발전소 카드 또는 지도 마커 클릭 시 설비 모니터링 화면으로 이동

### 3.2 설비 모니터링 (`monitoring`)
- 컴포넌트: `MonitoringView`
- 목적: 발전소 > 발전기 > 자산 > 센서 상세 단계별 모니터링
- 내부 상태 화면
  - 발전기 목록(`gen`)
  - 자산 목록(`asset`)
  - 센서/지표 상세(`sensor`)
  - RAG 분석 연결(`rag`)
- 주요 UI
  - Breadcrumb 네비게이션
  - 발전기 카드(이상 부품 수, 상태)
  - 자산 카드(이상 점수, 상태)
  - 센서 그래프 카드(전류/온도/진동)
  - 그래프 상세 모달(현재/최대/평균/임계치)
  - AI분석 버튼(RAG 화면 연계)
- 사용자 동작
  - 발전기 클릭 -> 자산 목록
  - 자산 클릭 -> 센서 상세
  - 그래프 클릭 -> 상세 모달
  - AI분석 클릭 -> RAG 상세 화면

### 3.3 이상 징후 이력 (`alerts`)
- 컴포넌트: `AlertView`
- 목적: 알람 발생 이력 및 조치 상태 확인
- 주요 UI
  - 필터 탭: 전체 보기 / 미확인 대상
  - 검색 입력(알람 ID)
  - 알람 테이블
    - ID, 발생 시각, 설비 위치, 알람 내용, 이메일 발송, 관리
  - 미확인 알람 `확인 처리` 버튼
- 사용자 동작
  - 필터 변경으로 목록 재표시
  - 확인 처리 버튼 클릭(현재는 상태 변경 로직 미구현)

### 3.4 AI 분석 (`rag`)
- 컴포넌트: `RAGView`
- 목적: 이상 징후 리포트 목록/상세 열람
- 주요 UI
  - 초기 로딩 스켈레톤
  - 분석 리포트 카드 목록
  - 리포트 상세(분석요약/원인분석/권고조치)
  - PDF 버튼, 재분석 버튼(현재 동작 미구현)
- 사용자 동작
  - 리포트 선택 -> 상세 보기
  - 뒤로가기(목록 또는 모니터링 화면)

### 3.5 유저 관리 (`admin`)
- 컴포넌트: `AdminView`
- 목적: 알림 수신자/계정 권한/발송 이력 관리
- 서브탭
  - 알림 수신자 설정(`emails`)
  - 계정/권한 관리(`users`)
  - 알림 발송 이력(`logs`)
- 주요 UI
  - 신규 수신자 등록 모달
  - 신규 계정 생성 모달
  - 알림 메시지 상세 모달
  - 로그 발전소 필터
- 사용자 동작
  - 등록/생성 폼 제출 시 `alert()` 표시(저장 미연동)
  - 로그 메시지 상세 팝업 조회

## 4. 화면 전환 흐름
1. 관제 지도에서 발전소 선택
2. 설비 모니터링(발전기 -> 자산 -> 센서 상세)
3. 필요 시 AI 분석(RAG) 연계
4. 알람 이력 확인 및 유저/수신자 관리 화면으로 이동

## 5. 반응형/테마
- 반응형: `grid-cols-*` 및 `md/lg/xl` breakpoint 기반
- 테마: `light/dark` CSS 변수 전환

## 6. 현재 구현 제한사항
- 데이터는 전부 로컬 목(Mock) 데이터
- 백엔드 API 호출 없음
- 검색/상세필터/확인처리/삭제/재분석/PDF 다운로드는 UI 중심(실제 처리 미연동)
