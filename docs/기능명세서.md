# KOWEPO Anomaly Dashboard 기능 명세서

## 1. 문서 개요
- 프로젝트명: `kowepo-anomaly-dashboard`
- 작성일: 2026-05-08
- 기준 소스: `src/components/*.tsx`, `src/constants.ts`, `src/types.ts`

## 2. 기능 분류

## 2.1 공통 기능
- 탭 전환 기능
  - 설명: 좌측 사이드바 메뉴 클릭 시 메인 화면 탭 전환
  - 입력: 메뉴 ID(`map`, `monitoring`, `alerts`, `rag`, `admin`)
  - 출력: 해당 컴포넌트 렌더링
- 사이드바 확장/축소
  - 설명: 좌측 메뉴 폭 256px/80px 토글
- 테마 전환
  - 설명: `light`/`dark` 전환, 루트 class 변경
- 현재시각 표시
  - 설명: 1초 간격으로 헤더 시각 갱신

## 2.2 관제 지도 기능
- 발전소 상태 시각화
  - 설명: 발전소별 지도 마커 및 상태 카드 표시
  - 데이터: `PLANTS`
- 발전소 선택
  - 설명: 카드/마커 클릭 시 선택 발전소 ID를 저장하고 모니터링 화면 이동

## 2.3 설비 모니터링 기능
- 발전기 목록 조회(목 데이터 생성)
  - 입력: `plantId`
  - 출력: 발전기 리스트(상태, 연료타입, 이상부품 수)
- 자산 목록 조회(목 데이터 생성)
  - 입력: `generatorId`
  - 출력: 자산 리스트(MSE, 온도/진동/전류)
- 센서 상세 시각화
  - 설명: 자산별 지표 그래프 카드 표시
  - 갱신 주기: 60초(랜덤 시뮬레이션)
- 그래프 상세 모달
  - 설명: 지표 클릭 시 상세 차트/통계(현재, 최대, 평균, 임계치)
- RAG 연계
  - 설명: `AI분석` 버튼으로 RAG 화면 진입
  - 매핑: 자산명 기준 초기 리포트 ID 선택

## 2.4 이상 징후 이력 기능
- 알람 목록 표시
  - 데이터: `MOCK_ALERTS`
  - 필드: ID, 시간, 위치, 메시지, 채널 상태, 처리상태
- 알람 상태 필터
  - 조건: 전체/미확인
- 알람 확인 처리 버튼
  - 현재 상태: 버튼 UI만 존재, 상태 변경 로직 미구현

## 2.5 AI 분석(RAG) 기능
- 분석 리포트 목록 표시
  - 데이터: `MOCK_REPORTS`
- 분석 리포트 상세 표시
  - 영역: 분석 요약, 원인 분석, 권고 조치
- 뒤로가기 처리
  - 컨텍스트에 따라 목록 또는 모니터링으로 복귀
- PDF/재분석 버튼
  - 현재 상태: UI만 존재, 동작 미구현

## 2.6 관리자 기능
- 서브탭 전환
  - 알림 수신자 설정 / 계정 권한 관리 / 알림 발송 이력
- 수신자 등록 모달
  - 입력: 이름, 이메일, 담당발전소
  - 제출 결과: 브라우저 alert 표시(저장 미연동)
- 계정 생성 모달
  - 입력: 사용자명, 사번/ID, 권한, 부서
  - 제출 결과: 브라우저 alert 표시(저장 미연동)
- 알림 발송 로그 필터
  - 조건: 발전소별 필터
- 로그 상세 보기
  - 설명: 메시지 페이로드 모달 출력

## 3. 데이터 모델 요약
- Plant: 발전소 기본정보/상태
- Generator: 발전기 상태/이상부품 수
- Asset: 자산별 상태 및 센서값
- Sensor: 센서 태그, 현재값, 변화율, 임계치
- Alert: 이상 알람 내역 및 채널 발송 상태
- AdminEmail: 수신자 정보 및 인증/활성 상태
- User: 사용자 권한 정보

## 4. 예외/제약사항
- 실제 인증/인가 없음
- 실제 API/DB 연동 없음
- 실시간 데이터는 랜덤 생성 기반
- 다수 버튼이 화면 동작만 구현된 상태
